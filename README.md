# Literary Atlas

A world literature exploration platform based on geographical discovery.

## Project Introduction

Literary Atlas connects literature with geographical locations, helping users explore authors, literary works, cities, and literary movements around the world.

## Technology Stack

- Frontend: Vue 3, Vite, JavaScript
- Backend: Python, FastAPI
- Database: SQLite
- Map: Leaflet
